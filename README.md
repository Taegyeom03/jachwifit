# 자취핏

자취생이 최소 비용으로 건강하게 다이어트하도록, 남은 칼로리 안에서 부족한 단백질을 가장 싸게 채우는 메뉴를 양과 가격까지 알려주는 웹 앱입니다. (Next.js + TypeScript)

PRD: Google Docs「PRD」(한 단락 PRD · 6질문)

## 주요 기능

1. **목표 대비 식사 기록** (`/setup`, `/`)
   - 성별 · 나이 · 키 · 현재/목표 체중 · 활동량 · 감량 속도로 하루 목표 칼로리와 단백질, 예상 기간을 계산합니다.
     - 기초대사량: Mifflin-St Jeor 공식, 하루 소비 칼로리 = 기초대사량 × 활동계수
     - 목표 칼로리 = 하루 소비 칼로리 − 감량분(주당 감량 kg × 7,700 ÷ 7), 기초대사량보다 낮아지지 않게 맞춤
     - 목표 단백질 = 체중 × 1.2~1.6g (기본 1.4g)
     - 주당 1kg 감량, 기초대사량 하한 적용, 목표 체중 저체중 범위일 때 경고
   - 음식을 검색(자동완성)해 양(인분 또는 g)과 끼니를 기록하면 칼로리 · 단백질 · 탄수화물 · 지방 · 식이섬유 진행 막대와 부족분, 남은 칼로리, 식비를 보여 줍니다.
2. **가격 포함 추천** (`/` 아래쪽 카드)
   - 남은 칼로리를 넘지 않으면서 부족한 단백질을 가장 싸게 채우는 조합 3개를 양 · 가격과 함께 보여 줍니다.
   - 단백질/가격 효율 순 그리디. 100kcal당 단백질 7g 이상인 음식을 먼저 쓰고, 부족분을 넘게 채우면 비싼 음식부터 덜어냅니다.
3. **캘린더** (`/calendar`)
   - 날짜별 달성 여부를 색으로 표시합니다. 목표 이하 초록, 10% 이내 초과 노랑, 10% 넘게 초과 빨강
   - 날짜를 누르면 그날 먹은 음식과 합계를 보여 주고, 그 날짜의 기록을 고칠 수 있습니다.

계산과 추천은 AI 없이 규칙으로 처리합니다. 로그인 없이 한 사람이 쓰는 앱이라 기록은 브라우저 저장소(localStorage)에 저장합니다. 저장소 코드는 `lib/store.ts`에 모아 두어 나중에 DB로 옮길 수 있습니다.

## 음식 데이터

- `data/foods.csv`가 원본입니다. `npm run dev`와 `npm run build` 전에 `lib/foods.data.json`으로 자동 변환됩니다.
- 칸: `name, serving_label, serving_g, kcal, protein, carb, fat, fiber, price, price_source, price_date, nutrition_source, nutrition_date, tags` (영양 · 가격은 1회 제공량 기준, 태그는 `|`로 구분)
- **영양 정보 (51개 중 49개 공공데이터)**: 식품의약품안전처「전국통합식품영양성분정보」표준데이터(공공데이터포털)
  - 원재료(계란 · 바나나 · 고기 등): 원재료성식품 표준데이터(국가표준식품성분표)의 식품코드 1개
  - 가공식품(훈제 닭가슴살 · 즉석밥 등): 가공식품 표준데이터에서 이름이 맞는 제품들의 성분별 중앙값
  - 음식(제육볶음 · 떡볶이 등): 음식 표준데이터의 100g 기준값
  - 100g(ml) 기준값을 1회 제공량으로 환산합니다. 가공식품 중 식이섬유 값이 없는 제품은 0으로 둡니다.
  - 어떤 기록을 썼는지는 `nutrition_source`에 식품코드나 중앙값 개수로 적혀 있습니다.
  - 프로틴 음료 · 단백질 두유는 포털에서 받을 수 있는 5만 건 안에 맞는 제품이 없어 임시값입니다. 제품 라벨을 보고 직접 넣어야 합니다.
- **가격은 아직 임시값입니다.** KAMIS 소매가격 · 참가격 · 편의점 직접 조사 값으로 바꿀 예정입니다. 값을 바꾸면 `price_source`와 `price_date`도 함께 고칩니다.

### 공공데이터로 영양 정보 다시 만들기

```bash
node scripts/fetch-public-data.mjs ../public-data     # 공공데이터포털에서 받기 (약 120MB, 저장소에 넣지 않음)
node scripts/match-public-data.mjs ../public-data     # 음식별 규칙대로 찾아 data/foods.csv 갱신
```

음식을 추가하거나 매칭을 바꾸려면 `scripts/match-public-data.mjs`의 `RULES`를 고칩니다. 실행하면 음식마다 바뀐 칼로리 · 단백질이 출력되니 이상한 값이 없는지 확인합니다.

## 실행 방법

Node.js 18.18 이상이 필요합니다. 필요한 키나 환경변수는 없습니다.

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:3000)
```

배포용으로 실행하려면:

```bash
npm run build
npm start
```

Netlify 배포 설정은 `netlify.toml`에 있습니다.
