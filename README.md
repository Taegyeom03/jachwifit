# 자취핏 · 자취생을 위한 칼로리 플래너

> **바로 써 보기: https://jachwifit.netlify.app** (회원가입 · 로그인 없음, 휴대폰 · PC 모두 가능)

자취생이 **돈을 적게 쓰면서 건강하게 살을 빼도록** 돕는 웹 앱입니다.
키와 몸무게를 넣으면 하루에 얼마나 먹으면 되는지 계산해 주고, 먹은 음식을 기록하면
**남은 칼로리 안에서 부족한 단백질을 가장 싸게 채우는 메뉴**를 양과 가격까지 알려 줍니다.

> 예: 단백질이 112g 부족하고 1,896kcal가 남았다면
> → "고등어캔 ×2 + 마른 멸치 ×2 + 계란 ×2 · 단백질 78g · 572kcal · 약 4,100원"

### 오늘 화면의 버튼들

- **추천 카드:** 남은 칼로리를 넘지 않으면서 부족한 단백질을 가장 싸게 채우는 조합 3개. 음식마다 영양 · 가격 출처와 기준일이 적혀 있어요.
- **[🌙 야식 먹고 싶어]:** 남은 칼로리 안에서 **편의점 · 야식 메뉴만**으로 조합을 다시 찾아요. 단백질을 이미 채웠으면 가벼운 야식 목록을, 남은 칼로리가 100kcal 미만이면 초저칼로리 메뉴만 보여 줘요.
- **내가 산 가격 입력:** 음식을 검색해 고르면 바로 아래에 그 음식의 1회 가격과 출처가 나와요. [내가 산 가격 입력]으로 그 자리에서 가격을 바꿀 수 있어요.
- **치팅데이 체크:** 그날 칼로리 상한을 유지 칼로리(TDEE)까지 올려요. 무제한은 아니고, 단백질 목표는 그대로예요. 추천에 치킨 · 족발 같은 메뉴도 들어가요. 이번 주에 목표보다 많이 먹었으면 남은 날 하루에 얼마나 줄이면 되는지 **안내만** 해요(굶으라고 하지 않아요).

## 4. 숫자는 어떻게 계산하나요?

계산과 추천은 **AI 없이 정해진 규칙**으로 해요. 목표 화면에서 내 숫자가 들어간 계산 과정을 그대로 볼 수 있어요.

| 무엇 | 계산 |
|---|---|
| 기초대사량 (BMR) | Mifflin-St Jeor 공식. 남: 10×체중 + 6.25×키 − 5×나이 + 5 / 여: 같은 식 − 161 |
| 하루 소비 칼로리 (TDEE) | BMR × 활동계수 (1.2 ~ 1.9, 5단계) |
| **하루 목표 칼로리** | TDEE − (주당 감량 kg × 7,700 ÷ 7). 단, **BMR보다 낮아지지 않게** 맞춤 |
| **하루 목표 단백질** | 현재 체중 × 1.2~1.6g (기본 1.4g) |
| 지방 · 탄수화물 | 지방은 목표 칼로리의 25%, 남은 칼로리는 탄수화물 |
| 식이섬유 | 성별 · 나이별 충분섭취량 (2025 한국인 영양소 섭취기준) |
| 예상 기간 | 뺄 체중 × 7,700kcal ÷ (하루 적자 × 7) → 주 단위 |

**경고가 뜨는 경우:** 주당 1kg 감량, 기초대사량 하한이 적용됨, 목표 체중이 저체중(BMI 18.5 미만), 단백질 · 탄수화물이 권장 에너지 비율(탄수화물 50~65%, 단백질 10~20%, 지방 15~30%)을 벗어남.

**추천 방식:** 단백질 1g당 가격이 싼 음식부터 담아요. 100kcal당 단백질 7g 이상인 음식을 먼저 쓰고, 부족분을 넘게 채우면 비싼 음식부터 덜어 내요. 시작 음식을 바꿔 서로 다른 조합 3개를 만들어요.

**하루 식단 예시:** 끼니마다 밥 한 공기를 두고, 남은 칼로리로 단백질 반찬을 위 방식으로 채운 뒤, 그래도 남는 칼로리는 밥 반 공기 단위로 채워요. 목표보다 너무 적게 먹으면 근손실 · 요요 위험이 있어서예요.

## 5. 꼭 알아 둘 점

- **기록은 지금 쓰는 브라우저에만 저장돼요.** 서버나 계정이 없어서, 휴대폰과 PC의 기록이 서로 공유되지 않아요. 브라우저 데이터를 지우거나 시크릿 모드로 쓰면 기록이 사라져요. **주로 쓸 기기 하나를 정해 주세요.**
- **가격 중 일부는 임시값이에요.** 공공데이터에 없는 닭가슴살 제품 · 편의점 상품 · 외식 메뉴 등은 화면에 "가격 임시값"으로 표시돼요. **[가격] 메뉴에서 내가 산 가격을 넣으면** 추천 · 식비 · 식단 예시 · 인사이트가 모두 그 가격으로 바뀌어요("가격 내가 입력"으로 표시). 내 가격도 이 브라우저에만 저장되고, 이미 적은 기록의 식비도 새 가격으로 다시 계산돼요.
- **의료 조언이 아니에요.** 일반적인 추정치예요. 질환이 있거나 임신 중이라면 전문가와 상담하세요.

## 6. 음식 데이터는 어디서 왔나요?

음식은 **104개**예요. 자취생이 자주 먹는 원재료 · 편의점 · 간편식 · 외식 메뉴를 골랐어요. 영양 · 가격은 모두 **1회 제공량 기준**이에요.

| 항목 | 출처 | 개수 |
|---|---|---|
| 영양 정보 | 식품의약품안전처「전국통합식품영양성분정보」표준데이터 (공공데이터포털 파일) | 98개 |
| 영양 정보 | 식품의약품안전처「식품영양성분DB정보」Open API (파일에 없던 프로틴 음료 · 단백질 두유, 새로 넣은 돼지 안심 · 공기밥 · 간장 · 돼지갈비) | 6개 |
| 가격 | KAMIS 농축수산물 소매가격 (서울, 일별) | 24개 |
| 가격 | 한국소비자원 생필품 가격 정보 (참가격, 월별 중앙값, 1+1 행사 제외) | 29개 |
| 가격 | 임시값 (공공데이터 없음, 앱의 [가격] 메뉴에서 내 가격으로 바꿀 수 있음) | 51개 |

- 가공식품처럼 같은 이름의 제품이 여러 개면 **성분별 중앙값**을 써요.
- 어떤 기록을 썼는지는 `data/foods.csv`의 `nutrition_source` · `price_source` 칸에 식품코드나 중앙값 개수로 남아 있어요.

## 7. 개발자용: 코드 구조와 실행 방법

### 7.1 기술 스택

- **Next.js 15 (App Router) + React 19 + TypeScript** 한 앱. 별도 백엔드 서버는 없어요.
- 기록 저장: 브라우저 **localStorage** (`lib/store.ts`에 모아 두어 나중에 DB로 옮길 수 있음)
- 배포: **Netlify** — GitHub `main`에 올리면 자동으로 빌드 · 배포돼요 (`netlify.toml`)

### 7.2 폴더 구조

```
app/                      화면 (Next.js App Router)
├─ page.tsx · Today.tsx   오늘 화면 (/) : 기록 · 진행 막대 · 추천 · 야식 · 치팅데이
├─ setup/page.tsx         시작 · 목표 설정 (/setup)
├─ plan/page.tsx          내 계획 (/plan) : 달성 예정일 · 체중 그래프 · 식단 예시
├─ calendar/page.tsx      캘린더 (/calendar)
├─ insights/page.tsx      인사이트 (/insights)
├─ prices/page.tsx        내 가격 (/prices) : 임시값 가격을 내가 산 가격으로
├─ components/            음식 검색(FoodAdder) · 가격 입력(PriceEditor) · 추천 카드(Recommendations) · 야식(NightSnack) · 메뉴(Nav)
├─ useAppData.ts          저장된 목표 · 기록 읽기/쓰기

└─ foods.data.json        ← data/foods.csv에서 자동 생성 (직접 고치지 않기)
```

### 7.3 내 컴퓨터에서 실행하기

[Node.js](https://nodejs.org) 18.18 이상이 필요해요. 앱을 실행하는 데는 키나 환경변수가 필요 없어요.

```bash
npm install
npm run dev        # http://localhost:3000
```

배포용으로 빌드해 보려면:

```bash
npm run build
npm start
```

> `npm run dev` · `npm run build` 전에 `data/foods.csv` → `lib/foods.data.json` 변환(`npm run foods`)이 자동으로 실행돼요.

### 7.4 음식 데이터 고치기 · 다시 만들기

**값 하나만 고칠 때:** `data/foods.csv`를 직접 고치고 `npm run foods`를 실행하면 돼요. 가격을 고쳤다면 `price_source` · `price_date`도 같이 고쳐 주세요. 새 음식은 **맨 뒤에** 붙여야 해요(앞에 넣으면 음식 번호가 바뀌어 기존 기록이 다른 음식을 가리켜요).

**칸 설명 (`data/foods.csv`)**

| 칸 | 뜻 |
|---|---|
| `name` · `serving_label` · `serving_g` | 이름 · 1회 제공량 표시(예: 1공기(210g)) · 1회 제공량 g |
| `kcal` · `protein` · `carb` · `fat` · `fiber` | 1회 제공량당 영양 |
| `price` · `price_source` · `price_date` | 1회 제공량 가격(원) · 출처(임시값이면 "임시값") · 기준일 |
| `nutrition_source` · `nutrition_date` | 영양 출처 · 기준일 |
| `tags` | `원재료` · `편의점` · `간단조리` · `야식` · `치팅` (`\|`로 구분). 야식 추천 · 치팅데이 후보에 쓰여요 |

**공공데이터로 영양 정보 다시 만들기**

```bash
node scripts/fetch-public-data.mjs ../public-data     # 공공데이터포털 파일 받기 (약 120MB, 저장소에 넣지 않음)
node scripts/match-public-data.mjs ../public-data     # 음식별 규칙(RULES)대로 찾아 data/foods.csv 갱신
```

파일에 없는 음식은 식약처 **Open API**로 채워요. [공공데이터포털](https://www.data.go.kr/data/15127578/openapi.do)에서「식품의약품안전처_식품영양성분DB정보」를 활용신청(개발계정 자동승인)하고, 마이페이지의 **일반 인증키(Decoding)**를 `.env.local`에 넣어요.

```bash
# .env.local (git에 올라가지 않아요)
DATA_GO_KR_KEY=발급받은키
```

```bash
node scripts/fetch-nutrition-api.mjs           # 찾은 제품과 바뀔 값 미리보기 (파일은 안 바뀜)
node scripts/fetch-nutrition-api.mjs --write   # data/foods.csv 갱신
```

- 새 음식을 API로 추가하려면 `scripts/fetch-nutrition-api.mjs`의 `RULES`에 `add`(제공량 · 가격 · 태그)와 `code`(식품코드) 또는 검색어를 넣어요. `match-public-data.mjs`의 `RULES`에도 같은 이름을 `keepTemp`로 넣어야 다시 돌려도 API 값이 유지돼요.

**공공데이터로 가격 다시 만들기**

KAMIS 인증키는 [kamis.or.kr](https://www.kamis.or.kr) Open API에서 무료로 발급받아요.

```bash
KAMIS_CERT_KEY=발급키 KAMIS_CERT_ID=발급ID node scripts/fetch-public-prices.mjs ../public-prices   # KAMIS 당일 + 참가격 최신 월
node scripts/match-public-prices.mjs ../public-prices                                              # 음식별 규칙대로 가격 갱신
```

음식별 상품과 환산 비율은 `scripts/match-public-prices.mjs`의 `RULES`에 있어요.

> 키는 어떤 것도 저장소에 넣지 않아요. `.env*` 파일은 `.gitignore`에 들어 있어요.

## 9. 용어 정리

| 용어 | 뜻 |
|---|---|
| 기초대사량 (BMR) | 가만히 있어도 하루에 쓰는 최소 칼로리. 이보다 적게 먹으면 몸에 무리가 가요 |
| 하루 소비 칼로리 (TDEE) | 활동까지 포함해 하루에 실제로 쓰는 칼로리 = 유지 칼로리 |
| 하루 적자 | TDEE − 목표 칼로리. 7,700kcal가 쌓이면 약 1kg이 빠진다고 봐요 |
| 1회 제공량 | 한 번에 먹는 기준 양 (예: 계란 1개, 공기밥 1공기 210g) |
| 임시값 | 공공데이터에 없어 대략 넣어 둔 값. 화면에 "임시값"으로 표시돼요 |
| 내 가격 | 내가 실제로 산 가격. [가격] 메뉴나 음식을 고를 때 입력하고, 화면에 "가격 내가 입력"으로 표시돼요 |
| 치팅데이 | 그날만 칼로리 상한을 유지 칼로리까지 올리는 날 (단백질 목표는 유지) |
| 성공 지표 | 최근 7일 기록 일수, 추천이 남은 칼로리를 넘은 건수, 단백질 부족분 평균 충족률(목표 80%) |
