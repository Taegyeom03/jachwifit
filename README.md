# 자취핏

자취생이 최소 비용으로 건강하게 다이어트하도록, 남은 칼로리 안에서 부족한 단백질을 가장 싸게 채우는 메뉴를 양과 가격까지 알려주는 웹 앱입니다. (Next.js + TypeScript)

PRD: Google Docs「PRD」(한 단락 PRD · 6질문)

## 주요 기능

1. **목표 대비 식사 기록** (`/setup`, `/`)
   - 성별 · 나이 · 키 · 현재/목표 체중 · 활동량 · 감량 속도로 하루 목표 칼로리와 단백질, 예상 기간을 계산합니다.
     - 기초대사량: Mifflin-St Jeor 공식, 하루 소비 칼로리 = 기초대사량 × 활동계수
     - 목표 칼로리 = 하루 소비 칼로리 − 감량분(주당 감량 kg × 7,700 ÷ 7), 기초대사량보다 낮아지지 않게 맞춤
     - 목표 단백질 = 체중 × 1.2~1.6g (기본 1.4g)
     - 지방 25%, 남은 칼로리는 탄수화물. 식이섬유는 성별 · 나이별 충분섭취량
       ([2025 한국인 영양소 섭취기준](https://www.kns.or.kr/), 보건복지부 · 한국영양학회 요약표)
     - 주당 1kg 감량, 기초대사량 하한 적용, 목표 체중 저체중 범위, 단백질 · 탄수화물이 권장 에너지 비율
       (탄수화물 50~65%, 단백질 10~20%, 지방 15~30%)을 벗어날 때 경고
     - 화면에 입력값이 들어간 계산 과정을 그대로 보여 줍니다.
   - 음식을 검색(자동완성)해 양(인분 또는 g)과 끼니를 기록하면 칼로리 · 단백질 · 탄수화물 · 지방 · 식이섬유 진행 막대와 부족분, 남은 칼로리, 식비를 보여 줍니다.
2. **가격 포함 추천** (`/` 아래쪽 카드)
   - 남은 칼로리를 넘지 않으면서 부족한 단백질을 가장 싸게 채우는 조합 3개를 양 · 가격과 함께 보여 줍니다.
   - 단백질/가격 효율 순 그리디. 100kcal당 단백질 7g 이상인 음식을 먼저 쓰고, 부족분을 넘게 채우면 비싼 음식부터 덜어냅니다.
   - 음식마다 영양 · 가격 출처와 기준일을 글자로 보여 주고, 임시값은 따로 표시합니다.
3. **캘린더** (`/calendar`)
   - 날짜별 달성 여부를 색으로 표시합니다. 목표 이하 초록, 10% 이내 초과 노랑, 10% 넘게 초과 빨강
   - 날짜를 누르면 그날 먹은 음식과 합계를 보여 주고, 그 날짜의 기록을 고칠 수 있습니다.
   - **성공 지표 (PRD Q6)**: 최근 7일 기록 일수 · 연속 일수, 추천이 남은 칼로리를 넘은 건수, 단백질 부족분 평균 충족률(목표 80%)을 보여 줍니다.
     추천 결과는 기록이 있는 날, 오늘 화면에서 마지막으로 본 첫 번째 추천 조합 기준으로 저장됩니다(`lib/success.ts`).

### 추가 기능 (핵심 3개 다음, 발표 전)

- **데이터 인사이트** (`/insights`): 단백질 가성비 TOP 10(단백질 1g당 가격, 공공데이터 가격만 보기 가능), 칼로리 대비 단백질 TOP 10, 최근 7일 칼로리 막대 · 평균 칼로리 · 단백질 달성 일수 · 평균 식비 · 끼니별 칼로리 비중
- **야식 추천** (오늘 화면 [야식 먹고 싶어] 버튼): 남은 칼로리 안에서 야식 · 편의점 음식만으로 단백질을 채우는 조합(없으면 간단조리까지), 단백질 목표를 채운 날은 가벼운 야식 목록, 남은 칼로리가 100kcal 미만이면 초저칼로리 메뉴만 안내
- **치팅데이** (오늘 화면 체크): 그날 칼로리 상한을 유지 칼로리(하루 소비 칼로리)까지 올리고 단백질 목표는 유지, 추천 후보에 치킨 · 족발 같은 "치팅" 음식 포함, 캘린더 ★ 표시. 이번 주(월~오늘) 목표보다 더 먹었으면 남은 날 하루에 줄일 칼로리를 안내만 하고(매일 목표는 그대로), 기초대사량 아래로는 줄이라고 하지 않습니다.

계산과 추천은 AI 없이 규칙으로 처리합니다. 로그인 없이 한 사람이 쓰는 앱이라 기록은 브라우저 저장소(localStorage)에 저장합니다. 저장소 코드는 `lib/store.ts`에 모아 두어 나중에 DB로 옮길 수 있습니다.

## 음식 데이터

- `data/foods.csv`가 원본입니다. `npm run dev`와 `npm run build` 전에 `lib/foods.data.json`으로 자동 변환됩니다.
- 칸: `name, serving_label, serving_g, kcal, protein, carb, fat, fiber, price, price_source, price_date, nutrition_source, nutrition_date, tags` (영양 · 가격은 1회 제공량 기준, 태그는 `|`로 구분)
- 음식은 **100개**입니다. 자취생이 자주 먹는 원재료 · 편의점 · 간편식 · 외식 메뉴를 골랐습니다.
- **영양 정보 (100개 모두 공공데이터)**: 식품의약품안전처「전국통합식품영양성분정보」표준데이터(공공데이터포털)
  - 원재료(계란 · 채소 · 고기 등): 원재료성식품 표준데이터(국가표준식품성분표)의 식품코드 1개
  - 가공식품(훈제 닭가슴살 · 즉석밥 · 너겟 등): 가공식품 표준데이터에서 이름이 맞는 제품들의 성분별 중앙값
  - 음식(제육볶음 · 김밥 · 찌개 등): 음식 표준데이터의 100g 기준값(여러 개면 중앙값)
  - 100g(ml) 기준값을 1회 제공량으로 환산합니다. 가공식품 중 식이섬유 값이 없는 제품은 0으로 둡니다.
  - 어떤 기록을 썼는지는 `nutrition_source`에 식품코드나 중앙값 개수로 적혀 있습니다.
  - 프로틴 음료 · 단백질 두유는 포털 파일(5만 건)에 맞는 제품이 없어, 같은 DB의 Open API(식품영양성분DB정보)로 이름 검색한 제품들의 중앙값을 씁니다 (아래 `fetch-nutrition-api.mjs`).
- **가격 (100개 중 53개 공공데이터)**: 1회 제공량 기준으로 환산합니다.
  - 원재료 24개: KAMIS 농축수산물 소매가격(서울, 일별)
  - 가공식품 29개: 한국소비자원 생필품 가격 정보(참가격, 월별) 해당 상품 조사값의 중앙값 (1+1 행사 제외)
  - 나머지 47개(닭가슴살 제품 · 그릭요거트 · 편의점 상품 · 외식 메뉴 등)는 공공데이터에 없어 임시값입니다. 편의점 · 마트에서 직접 조사해 넣고 `price_source`와 `price_date`를 함께 고칩니다.

### 공공데이터로 영양 정보 다시 만들기

```bash
node scripts/fetch-public-data.mjs ../public-data     # 공공데이터포털에서 받기 (약 120MB, 저장소에 넣지 않음)
node scripts/match-public-data.mjs ../public-data     # 음식별 규칙대로 찾아 data/foods.csv 갱신
```

음식을 추가하거나 매칭을 바꾸려면 `scripts/match-public-data.mjs`의 `RULES`를 고칩니다. 실행하면 음식마다 바뀐 칼로리 · 단백질이 출력되니 이상한 값이 없는지 확인합니다.

파일(5만 건)에 없는 프로틴 음료 · 단백질 두유는 식약처「식품영양성분DB정보」Open API로 이름 검색해 채웁니다. 공공데이터포털에서 활용신청(개발계정 자동승인) 후 일반 인증키(Decoding)를 `.env.local`의 `DATA_GO_KR_KEY`에 넣습니다. 키는 저장소에 넣지 않습니다.

```bash
node scripts/fetch-nutrition-api.mjs           # 찾은 제품과 바뀔 값 미리보기
node scripts/fetch-nutrition-api.mjs --write   # data/foods.csv 갱신
```

API로 채운 값은 `match-public-data.mjs`를 다시 돌려도 유지됩니다.

### 공공데이터로 가격 다시 만들기

KAMIS 인증키는 [kamis.or.kr](https://www.kamis.or.kr) Open API에서 무료로 발급받습니다. 키는 저장소에 넣지 않습니다.

```bash
KAMIS_CERT_KEY=발급키 KAMIS_CERT_ID=발급ID node scripts/fetch-public-prices.mjs ../public-prices   # KAMIS 당일 + 참가격 최신 월
node scripts/match-public-prices.mjs ../public-prices                                              # 음식별 규칙대로 가격 갱신
```

음식별 상품과 환산 비율은 `scripts/match-public-prices.mjs`의 `RULES`에 있습니다.

## 실행 방법

Node.js 18.18 이상이 필요합니다. 필요한 키나 환경변수는 없습니다.

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:3000)
```

배포용으로 실행하려면:

```bash
npm run build
npm start
```

Netlify 배포 설정은 `netlify.toml`에 있습니다.
